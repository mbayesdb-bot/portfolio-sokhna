# Portfolio premium — Sokhna Mbaye

Site statique responsive, en français, sans installation ni compilation. Identité visuelle inspirée du CV 2026 : bleu pétrole, corail, jaune, fond clair. Animations discrètes, navigation mobile et accessibilité (réduction des animations si demandée).

## Publier avec GitHub + Vercel
1. Sur GitHub, ouvrez le dépôt `portfolio-sokhna`.
2. Ajoutez **le contenu** de ce dossier (pas le ZIP) à la racine du dépôt. Si le dépôt contient déjà une ancienne version, remplacez `index.html`, `styles.css`, `script.js`, `vercel.json`, `README.md` et le dossier `assets`.
3. Dans Vercel : Add New > Project > Import Git Repository > sélectionnez le dépôt.
4. Framework Preset : **Other**. Aucun Build Command nécessaire. Cliquez sur **Deploy**.
5. Les modifications futures poussées sur GitHub seront publiées automatiquement.
